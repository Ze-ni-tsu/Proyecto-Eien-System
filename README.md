# Proyecto de Grado Eien-System

## ¿De que trata?

Es un sistema web de gestión logística para una empresa de envíos ficticia, Kizuna Logística S.A.S. Digitaliza todo el recorrido de un paquete:

- **Despachador:** registra el paquete en bodega, con peso, dimensiones y destinatario.

- **Asignación:** el paquete se asigna a un conductor y a un vehículo que tenga capacidad para llevarlo.

- **Conductor:** desde el celular ve su hoja de ruta, cambia el estado de cada entrega y captura la evidencia (firma en pantalla o foto).

- **Cliente final:** consulta dónde va su paquete con un código de seguimiento.

- **Administrador:** gestiona usuarios y, si alcanzamos, ve indicadores de entregas a tiempo frente a retrasadas.

Todo con registro de auditoría (quién cambió qué y cuándo) y contraseñas protegidas.

## Dato Curioso

El nombre viene de **永遠 (eien)**, “eternidad”.
